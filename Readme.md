📌 UEFA Euro Historical Analysis – Power BI Project
📊 Project Overview

This project analyzes the historical data of UEFA European Championship tournaments.
The dashboard explores winning trends, hosting influence, and competition evolution over time.

🎯 Objectives

Identify the most dominant countries in tournament history

Analyze the impact of hosting on winning probability

Track tournament expansion and team growth across eras

Visualize geographic distribution of winners and hosts

🛠 Tools & Technologies

Power BI

Power Query (Data Cleaning & Transformation)

DAX (Data Analysis Expressions)

Bing Maps Visualization

📈 Key Insights

Spain and Germany dominate tournament history.

Hosting the tournament does not always guarantee winning.

Number of participating teams increased significantly after 1996.
